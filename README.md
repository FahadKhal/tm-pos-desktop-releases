# TM POS for Windows

Downloads of the TM POS desktop app for Windows 10 and 11.

**[Download the latest version](https://github.com/FahadKhal/tm-pos-desktop-releases/releases/latest/download/TM-POS-Setup.exe)**

- Opens TM POS in its own window, with USB receipt and label printers.
- Keeps selling when the internet is down; sales sync by themselves when it is back.
- The first start needs the internet once to sign in and save your products.

Each release lists the file's SHA-256 fingerprint so you can check the download.

Windows may show "Windows protected your PC" while the app is not yet code-signed:
click **More info**, then **Run anyway**.

This repository holds installers only. More at https://tmpos.riggt.com
